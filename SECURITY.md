# Security policy

Please do not include secrets, personal data, private recordings, or a working exploit in a public
issue, discussion, pull request, test fixture, or screenshot.

Report a vulnerability through this repository's **Security** tab using GitHub private vulnerability
reporting. If private reporting is unavailable, open a minimal issue asking the maintainers to enable
a private reporting channel; do not include vulnerability details in that issue.

When reporting privately, include the affected route or component, reproduction steps, impact, and a
suggested mitigation if you have one. Remove unrelated account data and use synthetic identifiers.

Supported security fixes target the latest commit on `main`. Older snapshots and generated demo
artifacts are not maintained releases.
